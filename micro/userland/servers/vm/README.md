# vm 用户态虚拟内存策略

VM 服务记录地址空间中允许访问的区间，并在页首次访问时分配物理帧。模型从合成缺页事件出发，按需分配并清零匿名页。分配、清零、映射和撤销映射由内存替身完成。 [内核内存模型](../../../kernel/memory/README.md)

## 最小模型

```text
Region   = (address_space, [lo, hi), rights)
VM       = (regions, resident)
resident : (address_space, virtual_page) ⇀ frame

无区间 ──reserve──> 已预留 ──合法缺页──> 已预留且相应页已映射
                        └──release───────────────> 无区间
```

| 操作 | 迁移 |
| --- | --- |
| `reserve(as, lo, len, rights)` | 检查非空区间的页对齐、范围和权限，确认终址计算无溢出、区间无冲突后登记 |
| `fault(as, va, access)` | 查找区间并检查访问权限。有驻留页时复用，否则分配一帧、清零并映射，完成后返回 `RESUME` |
| `release(as, lo, len)` | 对完整匹配的区间逐页撤销驻留映射，再移除区间 |

缺页映射成功后，页表持有映射引用，服务释放临时分配引用。映射失败时释放临时帧，当页仍处于已预留状态。模型中的内存替身保证可撤销它创建的有效映射。

## 不变量

1. 同一地址空间内的区间互不重叠。不同地址空间各自管理虚拟页。
2. 驻留页落在所属区间内，每个虚拟页最多一条映射，权限受区间限制。
3. 只有区间内且访问权限成立的缺页可以建立映射。新建匿名页对用户可见前已清零。
4. 释放区间同时移除其驻留页记录和映射引用。

## 独立验证

预留两页，连续两次访问同一页，检查只分配一帧。用越界、写只读页以及映射失败验证拒绝及回收，最后释放区间并比对帧计数。

## QEMU demo

`vm.c` 实现区间表与驻留页表。内存替身检查映射前的整页清零，以及撤销映射时释放的引用。

```sh
make -C micro/userland/servers/vm run
```

从仓库根目录运行，成功时输出 `[vm] PASS` 并退出 QEMU。

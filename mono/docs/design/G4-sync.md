# G4 同步与互斥（信号量 + 等待队列）

- 王道：2.3 同步与互斥
- 汤小丹：第 3 章 进程同步

## 实现

- `struct sem`：计数 + PCB 等待队列。
- `sem_wait`：关中断后循环检查计数；为 0 时把当前进程置 SLEEPING 并 `sched()`。
- `sem_post`：关中断、计数加一、唤醒队首等待者（置 READY），不直接切换。
- `mutex` 是计数为 1 的信号量包装。
- 生产者-消费者：N=8、1000 次；空槽/满槽/互斥三个信号量。

## 丢失唤醒的处理

检查条件和进入睡眠在同一个关中断区间内完成；`sem_post` 也关中断修改计数和等待队列。这样不会出现“刚检查完就 post，然后睡死”的窗口。

## 取舍

- 不做管程、条件变量、用户态 futex/POSIX 语义。
- 单核，关中断足够；没有真正的多核自旋锁。
- 等待队列固定长度 `MAX_PROCS`，溢出直接 panic（教学规模足够）。

# G12 磁盘请求调度（SCAN）

- 王道：5.3 磁盘和固态硬盘
- 汤小丹：第 9 章 磁盘访问调度

## 实现

- 采用 **SCAN**（电梯算法），从当前磁头 53 向大号方向移动。
- 请求序列：98、183、37、122、14、124、65、67。
- 输出顺序：65、67、98、122、124、183、37、14。
- 教学简化：把块号直接当柱面号；没有真实寻道延迟模型、没有 NCQ/FTL。

## 与教材的对应

- 先服务同方向最近的请求，到达一端后反向；避免 FCFS 的来回抖动。
- 不实现 C-SCAN、LOOK、SSTF；只做一种并在文档中写明。

## 验收

```bash
make && timeout 10s make run
# [disk] SCAN from 53 (up): 65 67 98 122 124 183 37 14
```

## 已知限制

- 调度器是独立自测，没有接入 G9 的 `bread` 请求队列；真实块 I/O 仍是同步直读。

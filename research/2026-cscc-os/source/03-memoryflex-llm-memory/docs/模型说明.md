# 模型清单与复现方式

阶段 0–3 使用以下 GGUF 模型（Q4_K_M 量化）。因 GitLab 平台对单次推送/解包有
大小限制（实测普通推送 1GB 级即被服务端拒绝，Git LFS 亦报错），模型文件不进入
版本库，保留在本地 `models/` 目录；全部模型来自公开 HuggingFace 仓库，可用
`scripts/download_models.ps1` 一键下载复现。

| 模型 | 文件 | 大小 | 用途 | 来源 |
|---|---|---:|---|---|
| Qwen2.5-1.5B-Instruct | qwen2.5-1.5b-instruct-q4_k_m.gguf | 1.07 GB | dense 基线/集群实例 | Qwen/Qwen2.5-1.5B-Instruct-GGUF |
| Qwen2.5-3B-Instruct | qwen2.5-3b-instruct-q4_k_m.gguf | 2.10 GB | dense 基线/集群实例 | Qwen/Qwen2.5-3B-Instruct-GGUF |
| OLMoE-1B-7B-0125 | OLMoE-1B-7B-0125-Q4_K_M.gguf | 4.21 GB | MoE 专家激活/页级专家锁定 | allenai/OLMoE-1B-7B-0125-GGUF |

下载（断点续传，国内走 hf-mirror）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download_models.ps1 -ModelId qwen2.5-1.5b
powershell -ExecutionPolicy Bypass -File scripts\download_models.ps1 -ModelId qwen2.5-3b
powershell -ExecutionPolicy Bypass -File scripts\download_models.ps1 -ModelId olmoe-1b-7b
```

说明：所有实验数据、分析脚本、llama.cpp 源码（含 MemoryScheduler/专家追踪补丁）、
报告与图表均已入库；模型文件由上述脚本保证可复现。

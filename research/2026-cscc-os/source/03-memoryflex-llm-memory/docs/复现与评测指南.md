# 项目复现与评测指南

## 1. 环境与版本清单（可复现基线）

| 项目 | 版本/值 |
|---|---|
| 系统 | Windows（PowerShell 7+），i9-13900HX / RTX 4050 6GB / 16GB RAM |
| 引擎 | llama.cpp commit `11924d4`（GitCode 镜像） |
| 引擎补丁 | `patches/llama-memory-scheduler.patch`（MemoryScheduler + 软件预取 + 专家追踪，全部环境变量开关、默认零开销） |
| CUDA | 12.4（构建时需 `CUDA_PATH_V13_0` 指向 v12.4 以规避 VS 残留） |
| 模型 | Qwen2.5-1.5B/3B（dense）、OLMoE-1B-7B（MoE），Q4_K_M（清单见 `docs/模型说明.md`） |
| Python | 3.11 + psutil/requests/matplotlib/numpy；GGUF 解析用 llama.cpp 自带 gguf-py |

一键复现流程：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_env.ps1        # 环境自检
powershell -ExecutionPolicy Bypass -File scripts\build_llamacpp.ps1   # 编译（gitcode 镜像）
powershell -ExecutionPolicy Bypass -File scripts\download_models.ps1  # 下载模型（hf-mirror）
```

注意：MemoryScheduler 依赖进程工作集裁剪/页锁定，**实验必须以本机账户权限运行**（沙箱会失败）。

## 3. 与 FlexInfer 论文的对齐与差异（诚实对照）

**机制对齐**（我们的移植/实现）：
- 平衡内存锁定：FFN 优先、按层均匀、Attention 兜底（Algorithm 1 移植，含 GQA 张量层级）；
- 预取窗口 k：常驻内存 ≈ 锁定集合 + k/n 窗口（论文的 k/n 压缩比）；
- 换出策略：参数一次使用后释放（工作集裁剪实现"用后即换出"）。

**数值差异与原因**（不直接对比具体倍数）：
- FlexInfer：Llama2-7B~70B 服务器 CPU + 冷 SSD，cgroup 限制，10.6–12.5× vs mmap；
- 本项目：1.5B/3B 笔记本 CPU + **页缓存常热**，缺页以软缺页（页表开销）为主；
- 因此本项目呈现的是"预算-吞吐/缺页"曲线与预取的重叠收益（+10–14%），
  磁盘 IO 主导的冷存储场景下收益会按顺序读带宽比放大。

## 4. 已知边界

- MoE 专家预取（静态/动态）在本规模净负：触达集合与逐 token 激活错位 + 线程争抢；
- 集群实验 TTFT 噪声 ±5%（CPU 共享 + 热缓存）；论文 92% 对应 GPU 大规模 + 长前缀；
- Windows 无 per-page 换出 API：以工作集裁剪近似"换出"，锁定页常驻。

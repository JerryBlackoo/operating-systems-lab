# 阶段 0 基线结果（2026-08-02）

## 环境

- 硬件：i9-13900HX（24C/32T）、RTX 4050 Laptop 6GB、16GB RAM、Windows
- 引擎：llama.cpp（源码编译，commit `11924d4`，MSVC 19.43，CPU + CUDA 双后端，sm_89）
- 模型：Qwen2.5-1.5B/3B-Instruct GGUF Q4_K_M（1.04 GiB / 1.96 GiB）
- 测量：llama-server（127.0.0.1，ctx 2048，parallel 1）+ 流式 chat 请求，8 请求 × 48 token，逐行解析 SSE 计时；RSS 由 psutil 采样，显存由 nvidia-smi 轮询

## 备注

- 显存读数包含桌面进程占用（基线约 1.7GB），进程级显存需按 PID 查询（后续版本改进）。
- 阶段 0 目的：为后续 offload/预取/调度实验提供"满内存基线"对照。下一阶段将在此基线上引入内存预算控制（预取窗口、锁定预算、KV 上限）与 LMETRIC 调度。

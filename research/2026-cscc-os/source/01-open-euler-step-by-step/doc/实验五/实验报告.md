### 3.1 OpenEuler 内核模块：kmalloc 内存分配

编写内核模块，调用 kmalloc() 分配内存，并打印虚拟地址和物理地址。

\*\*核心代码（kmalloc\_test.c）：\*\*

```c

static int \_\_init kmalloc\_test\_init(void)

{

kmalloc\_ptr = kmalloc(ALLOC\_SIZE, GFP\_KERNEL);

phys\_addr = virt\_to\_phys(kmalloc\_ptr);

printk(KERN\_INFO "kmalloc allocated at virtual: %p, physical: %lx\n",

kmalloc\_ptr, phys\_addr);

return 0;

}

3.2 OpenEuler 内核模块：vmalloc 内存分配

c

四、实验结果

4.1 kmalloc 输出

text

[18401.174294] Loading kmalloc\_test module.

[18401.174464] kmalloc allocated memory at virtual address: 000000001ebd78c6

[18401.174738] Corresponding physical address: 11aea0000

分析：

虚拟地址：0x000000001ebd78c6

物理地址：0x11aea0000

kmalloc 分配的内存位于物理内存映射区域，物理地址连续

4.2 vmalloc 输出

text

[18433.488996] Loading vmalloc\_test module.

[18433.489233] vmalloc allocated memory at virtual address: 00000000a0311968

[18433.489375] Corresponding physical address: 20a5c1bf1000

分析：

虚拟地址：0x00000000a0311968

物理地址：0x20a5c1bf1000

vmalloc 分配的虚拟内存连续，但物理内存不一定连续

4.3 kmalloc vs vmalloc 对比

|  |  |  |
| --- | --- | --- |
| 特性 | kmalloc | vmalloc |
| 物理连续性 | 连续 | 不连续 |
| 最大分配大小 | ≤ 128KB | 无限制 |
| 分配速度 | 快 | 较慢 |
| 适用场景 | 小块内存、DMA | 大块内存 |

**五、思考题**

使用虚拟地址的意义？

1、隔离性：每个进程拥有独立的虚拟地址空间，互不干扰

2、安全性：防止进程访问其他进程的内存

3、简化内存管理：进程认为自己拥有全部内存

4、方便共享：不同进程可以映射到同一物理内存（如共享库）

# 四、进程与线程的区别

|  |  |  |
| --- | --- | --- |
| **特性** | **进程** | **线程** |
| 地址空间 | 独立 | 共享 |
| 资源开销 | 大 | 小 |
| 通信方式 | IPC | 全局变量 |
| 切换速度 | 慢 | 快 |
| 安全性 | 高 | 低 |

# 五、僵尸进程

产生原因：子进程结束后，父进程没有调用 wait() 或 waitpid() 回收子进程资源。

危害：占用进程ID和内核资源，可能导致系统无法创建新进程。

避免方法：

1、父进程调用 wait() 或 waitpid()

2、使用 signal(SIGCHLD, SIG\_IGN) 忽略子进程退出信号

3、双重 fork()

# 自旋锁 vs 互斥锁

|  |  |  |
| --- | --- | --- |
| **特性** | **自旋锁** | **互斥锁** |
| 等待方式 | 忙等待 | 休眠等待 |
| 适用场景 | 临界区很短 | 临界区较长 |
| 开销 | 无上下文切换 | 有上下文切换 |
| 缺点 | CPU浪费 | 切换开销 |

# 进程通信方式对比

|  |  |  |
| --- | --- | --- |
| **方式** | **优点** | **缺点** |
| 消息队列 | 有同步机制 | 速度较慢 |
| 共享内存 | 速度最快 | 需要自己实现同步 |
| 套接字 | 支持网络通信 | 复杂度高 |

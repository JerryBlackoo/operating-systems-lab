# 实验三：进程管理与通信

# ## 一、实验背景及实际运用

### 1.1 实验背景

在现代操作系统中，进程与线程是系统资源分配与调度的基本单位。理解进程的创建、终止、通信与同步机制，是掌握操作系统核心原理的关键。本实验基于 openEuler 操作系统，通过编程实践，帮助学生深入理解进程管理、线程通信、进程同步及 IPC（进程间通信）机制。

### 1.2 实际运用

| 应用场景 | 说明 |

| 服务器并发处理 | 使用多进程/多线程处理客户端请求 |

| 嵌入式系统 | 任务调度与资源管理依赖进程/线程模型 |

| 数据库系统 | 使用共享内存和信号量实现高效数据交换 |

| 操作系统内核 | 进程调度、中断处理、系统调用均涉及进程管理 |

| 分布式系统 | 消息队列用于节点间通信 |

### 1.3 本实验涉及的核心机制

| 机制 | 实际应用 |

| getpid() | 系统监控、进程管理工具（如 ps、top） |

| pthread | 多线程服务器、并行计算 |

| 僵尸进程 | 理解进程回收机制，避免资源泄露 |

| 自旋锁 | 多核 CPU 下的短临界区保护 |

| 信号量 | 生产者-消费者模型、资源池管理 |

| 消息队列 | 进程间异步通信、日志系统 |

| 共享内存 | 高频数据交换、数据库缓存 |

# ## 二、问题与解决

### 2.1 编译报错：undefined reference to `pthread\_create`

\*\*问题现象\*\*：

undefined reference to `pthread\_create'

text

\*\*原因\*\*：未链接 pthread 库。

\*\*解决方法\*\*：

gcc threadid.c -o threadid -pthread

2.2 僵尸进程无法回收

问题现象：

text

ps aux | grep Z

显示僵尸进程（状态为 Z）。

原因：父进程未调用 wait() 或 waitpid()。

解决方法：

wait(NULL); // 在父进程中添加

2.3 共享内存段错误（Segmentation fault）

问题现象：

text

Segmentation fault (core dumped)

原因：共享内存未正确创建或附加失败。

解决方法：

# 先运行写端创建共享内存

./write

# 再运行读端

./read

2.4 消息队列创建失败

问题现象：

text

msgget failed: No such file or directory

原因：key 生成失败或权限不足。

解决方法：

key\_t key = ftok("/tmp", 12345); // 确保路径存在

int msgid = msgget(key, 0666 | IPC\_CREAT);

2.5 git push 被拒绝

问题现象：

text

! [rejected] main -> main (fetch first)

原因：远程仓库有新的提交。

解决方法：

bash

git pull origin main --rebase

git push origin main

2.6 虚拟机网络不通

问题现象：

text

ping: baidu.com: Name or service not known

解决方法：

VMware 网络适配器设置为 NAT 模式

重启虚拟机

执行 dhclient ens33 获取 IP

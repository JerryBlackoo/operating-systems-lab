### 2.4 边界测试

#### 测试用例 4.1：文件名长度测试

**测试步骤**：
```bash
./fs_test disk.img create abcdefghijklmnopqrstuvwxyzabcde.txt 1
```

**预期结果**：
- 文件名超过 27 字符，应返回错误

**实际结果**：
```
Error: filename too long (max 27 chars)
```

**测试结论**：✅ 通过（正确拒绝）

---

#### 测试用例 4.2：最大文件数测试

**测试步骤**：
```bash
for i in {1..513}; do
  ./fs_test disk.img create file$i.txt 1
done
```

**预期结果**：
- 创建 512 个文件成功
- 第 513 个文件失败（inode 耗尽）

**实际结果**：
```
Created 512 files successfully.
Error: no free inode
```

**测试结论**：✅ 通过

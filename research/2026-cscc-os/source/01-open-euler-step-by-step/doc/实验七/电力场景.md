# 实验七 · 电力场景深度解读

## 场景背景

本实验模拟 **电力采集终端的本地存储系统**。在智能变电站、配电自动化终端（DTU/FTU）等场景中，嵌入式 Linux 设备需要在本地缓存电力采集数据、告警日志、配置文件等。本实验通过用户态文件系统模拟，让学生理解文件系统原理与电力数据存储的直接关联。

---

## 文件系统组件与电力对应物

| 文件系统组件 | 电力对应物 | 教学意义 |
|------------|-----------|----------|
| 虚拟磁盘 disk.img | 终端本地存储（eMMC/SD卡） | 理解块设备抽象 |
| 超级块 (Superblock) | 存储设备元信息 | 理解文件系统全局信息 |

| 块位图 | 数据块使用情况 | 理解存储分配 |

| 目录项 | 电力数据文件分类 | 理解目录结构 |
| 数据块 | 实际电力采集数据 | 理解数据存储 |

## 实际应用场景

### 1. 智能变电站数据缓存

变电站采集终端在通信中断时需要本地缓存数据：

- **电压数据文件**：`voltage.csv` - 实时电压采集记录
- **电流数据文件**：`current.csv` - 负载电流监测
- **功率数据文件**：`power.csv` - 功率计算结果
- **告警日志文件**：`alarm.log` - 过载、短路等告警
- **配置文件**：`config.ini` - 终端运行参数

### 2. 配电自动化终端日志存储

配电终端（DTU/FTU）的本地日志系统：

- **操作日志**：开关分合闸记录
- **事件日志**：故障事件、恢复事件
- **通信日志**：与主站通信记录
- **维护日志**：设备维护、升级记录

### 3. 电力物联网边缘节点

边缘计算节点的本地数据管理：

- **多传感器数据**：温度、湿度、振动
- **数据预处理结果**：滤波、异常检测结果
- **AI模型缓存**：本地推理模型文件

## 文件系统设计与电力场景的对应

### 1. 存储容量设计

| 参数 | 本实验值 | 电力终端实际值 | 说明 |
|------|---------|---------------|------|
| 磁盘大小 | 64 MB | 512 MB - 4 GB | 实际需存储更长时间数据 |
| inode 数量 | 512 | 1024 - 4096 | 实际需支持更多文件 |
| 单文件大小 | 8 KB | 1 MB - 10 MB | 实际数据文件更大 |
| 块大小 | 512 B | 4 KB | 实际采用更大块提升性能 |

### 2. 文件目录结构

模拟电力终端的典型目录结构：

```
/
├── data/
│   ├── voltage.csv      # 电压数据
│   ├── current.csv      # 电流数据
│   └── power.csv        # 功率数据
├── log/
│   ├── alarm.log        # 告警日志
│   ├── operation.log    # 操作日志
│   └── communication.log # 通信日志
└── config/
    ├── system.ini       # 系统配置
    └── threshold.conf   # 告警阈值
```

## 实验与实际开发的差异

| 实验模拟 | 实际开发 | 差异说明 |
|---------|---------|---------|
| 用户态 C 模拟 | 内核态文件系统（ext4/jffs2） | 实际需要内核驱动支持 |
| 内存虚拟磁盘 | eMMC/SD/NAND Flash | 实际需要块设备驱动 |
| 固定 64MB | 可变大小分区 | 实际需要分区管理 |
| 无磨损均衡 | Flash 需磨损均衡 | 实际需要 FTL 层 |
| 无文件系统检查 | 需要 fsck/journal | 实际需要日志和恢复机制 |

## 扩展思考与挑战

### 1. 增加循环日志

电力终端日志文件需要循环覆盖，避免磁盘写满：

```c
// 当日志文件超过阈值时，覆盖最旧的数据
if (file_size > LOG_MAX_SIZE) {
    // 实现循环日志逻辑
}
```

### 2. 数据压缩存储

电力采集数据有大量重复，可实现简单压缩：

```c
// 行程编码压缩电压数据
// 220.5,220.5,220.5,220.6 → (220.5,3),(220.6,1)
```

### 3. 文件权限管理

模拟电力终端的多用户访问：

```c
struct inode {
    // ... 其他字段
    int owner;      // 所有者 UID
    int permission; // rwx 权限
};
```

### 4. 数据完整性校验

为电力数据文件增加 CRC 校验：

```c
struct file_header {
    uint32_t magic;
    uint32_t crc32;    // 数据校验
    uint32_t size;
};
```

# 实验七：文件管理 - 设计方案

## 一、项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 赛题编号 | proj54 - OpenEuler 内核 Step by Step |
| 实验名称 | 实验七：文件管理 |
| 技术赛道 | 操作系统功能挑战赛道 |
| 开发环境 | Linux / Windows (跨平台) |
| 开发语言 | C 语言 |
| 开发工具 | GCC, Make |

### 1.2 功能目标

在**用户态**实现一个简单的文件系统模拟器，完整模拟文件系统的核心功能：

- **虚拟磁盘管理**：基于文件的块设备模拟
- **文件系统格式化**：初始化超级块、inode 表、位图
- **文件操作**：创建、打开、读取、写入、关闭、删除
- **目录管理**：目录项的增删改查

### 1.3 技术栈选型及理由

| 技术选型 | 理由 |
|---------|------|
| **用户态实现** | 避免内核开发复杂性，聚焦文件系统原理，便于调试和演示 |
| **C 语言** | 接近底层，指针操作灵活，便于模拟内存布局 |
| **基于文件的虚拟磁盘** | 无需真实块设备，跨平台兼容，便于保存和恢复状态 |
| **位图管理** | 空间效率高（1 bit 表示 1 块），算法简单高效 |
| **固定大小 inode** | 简化实现，固定 32 块 inode 表，最多支持 512 个文件 |

### 2.2 磁盘布局设计

虚拟磁盘采用经典的 Unix 风格布局：

```
┌──────────────────────────────────────────────────────────┐
│ 块号  │ 内容             │ 说明                           │
├───────┼──────────────────┼────────────────────────────────┤
│ 0     │ 超级块           │ 文件系统元数据                 │
│ 1     │ inode 位图       │ 记录 inode 使用情况 (512 bits) │
│ 2     │ 数据块位图       │ 记录数据块使用情况             │
│ 3-34  │ inode 表         │ 存储 inode 结构 (32 块)        │
│ 35+   │ 数据块           │ 存储文件内容                   │
└──────────────────────────────────────────────────────────┘

计算：
- inode 表大小: 32 块 × 512 字节/块 = 16384 字节
- 每个 inode 大小: 32 字节
- 最大 inode 数: 16384 / 32 = 512 个

数据块数量: 128000 - 35 = 127965 块
最大文件大小: 16 块 × 512 字节 = 8KB (单个文件)
```

### 2.3 核心数据结构

#### 超级块 (Superblock)

```c
/**
 * struct Superblock - 文件系统超级块
 *
 * 存储文件系统的整体元数据，位于磁盘块 0。
 */
typedef struct {
    uint32_t magic;            /* 魔数：0xDEADBEEF，用于识别文件系统 */
    uint32_t total_blocks;     /* 总块数：128000 */
    uint32_t free_blocks;      /* 空闲数据块数 */
    uint32_t inode_table_start;/* inode 表起始块：3 */
    uint32_t data_block_start; /* 数据块起始块：35 */
    uint32_t root_dir_inode;   /* 根目录 inode 号：固定为 0 */
} Superblock;
```

#### inode (索引节点)

```c
/**
 * struct Inode - 文件索引节点
 *
 * 存储文件的元数据和数据块指针。
 * 大小: 32 字节
 */
typedef struct {
    uint32_t inode_id;        /* inode 编号 */
    uint32_t size;            /* 文件大小 (字节) */
    uint32_t blocks[16];      /* 直接块指针 (最多 16 个数据块) */
    uint16_t type;            /* 类型: 0=空闲, 1=文件, 2=目录 */
    uint16_t ref_count;       /* 引用计数 (打开次数) */
} Inode;
```

**设计说明**：
- 使用 16 个直接块指针，支持最大 8KB 文件
- 未实现间接块，简化实现复杂度
- `type` 字段区分文件和目录

#### 目录项 (Directory Entry)

```c
/**
 * struct DirEntry - 目录项
 *
 * 用于目录结构，存储文件名与 inode 的映射。
 * 大小: 32 字节
 */
typedef struct {
    char filename[28];        /* 文件名 (最长 27 字符 + '\0') */
    uint32_t inode_num;       /* 对应的 inode 编号 */
} DirEntry;
```

**设计说明**：
- 文件名限制 28 字节，适合教学演示
- 每个目录项 32 字节，一个数据块可存储 16 个目录项

#### 文件描述符

```c
/**
 * struct FileDescriptor - 打开文件的描述符
 */
typedef struct {
    int inode_num;            /* inode 编号 */
    int flags;                /* 打开标志 */
    uint32_t offset;          /* 读写偏移量 */
    int used;                 /* 是否被使用: 1=使用, 0=空闲 */
} FileDescriptor;

#define MAX_OPEN_FILES 64     /* 最多同时打开 64 个文件 */
```

## 三、核心模块实现说明

### 3.1 虚拟磁盘模块 (disk.c)

```c
/**
 * Disk 结构体
 */
typedef struct {
    FILE *file;               /* 文件指针 */
    char *filename;           /* 文件名 */
    int total_blocks;         /* 总块数 */
} Disk;

/**
 * disk_init - 初始化虚拟磁盘
 * @filename: 磁盘镜像文件名
 *
 * 功能：打开磁盘文件，若不存在则创建
 * 返回：Disk 指针，失败返回 NULL
 */
Disk* disk_init(const char *filename);

/**
 * disk_read - 读取磁盘块
 * @disk: 磁盘指针
 * @block_num: 块号 (从 0 开始)
 * @buffer: 数据缓冲区 (至少 512 字节)
 *
 * 返回：0 成功, -1 失败
 */
int disk_read(Disk *disk, int block_num, void *buffer);

/**
 * disk_write - 写入磁盘块
 * @disk: 磁盘指针
 * @block_num: 块号
 * @buffer: 数据缓冲区
 *
 * 返回：0 成功, -1 失败
 */
int disk_write(Disk *disk, int block_num, const void *buffer);

/**
 * disk_close - 关闭磁盘
 */
void disk_close(Disk *disk);
```

**实现关键点**：
- 使用 `fseek()` 定位到指定块
- 每次读写固定 512 字节

```c
int disk_read(Disk *disk, int block_num, void *buffer) {
    if (fseek(disk->file, block_num * BLOCK_SIZE, SEEK_SET) != 0)
        return -1;
    if (fread(buffer, BLOCK_SIZE, 1, disk->file) != 1)
        return -1;
    return 0;
}

int disk_write(Disk *disk, int block_num, const void *buffer) {
    if (fseek(disk->file, block_num * BLOCK_SIZE, SEEK_SET) != 0)
        return -1;
    if (fwrite(buffer, BLOCK_SIZE, 1, disk->file) != 1)
        return -1;
    fflush(disk->file);  /* 立即写入磁盘 */
    return 0;
}
```

### 3.2 文件系统核心模块 (fs.c)

#### 格式化文件系统

```c
/**
 * fs_format - 格式化文件系统
 *
 * 步骤：
 * 1. 初始化超级块（块 0）
 * 2. 初始化 inode 位图（块 1）
 * 3. 初始化数据块位图（块 2）
 * 4. 初始化 inode 表（块 3-34）
 * 5. 创建根目录 inode（inode 0）
 */
int fs_format(Disk *disk) {
    Superblock sb = {
        .magic = 0xDEADBEEF,
        .total_blocks = TOTAL_BLOCKS,
        .free_blocks = TOTAL_BLOCKS - DATA_BLOCK_START,
        .inode_table_start = INODE_TABLE_START,
        .data_block_start = DATA_BLOCK_START,
        .root_dir_inode = 0
    };

    /* 写入超级块 */
    disk_write(disk, 0, &sb);

    /* 初始化 inode 位图：标记 inode 0 为已用 */
    char inode_bitmap[BLOCK_SIZE] = {0};
    inode_bitmap[0] = 0x01;  /* 根目录 inode */
    disk_write(disk, 1, inode_bitmap);

    /* 初始化块位图：标记元数据块为已用 */
    char block_bitmap[BLOCK_SIZE] = {0};
    for (int i = 0; i < DATA_BLOCK_START; i++) {
        block_bitmap[i / 8] |= (1 << (i % 8));
    }
    disk_write(disk, 2, block_bitmap);

    /* 创建根目录 inode */
    Inode root_inode = {
        .inode_id = 0,
        .size = 0,
        .type = 2,  /* 目录 */
        .ref_count = 1
    };
    write_inode(disk, 0, &root_inode);

    return 0;
}
```

#### 位图管理

```c
/**
 * alloc_inode - 分配一个空闲 inode
 *
 * 遍历 inode 位图，找到第一个空闲位并标记为已用
 * 返回：inode 编号，失败返回 -1
 */
int alloc_inode(FileSystem *fs) {
    char bitmap[BLOCK_SIZE];
    disk_read(fs->disk, 1, bitmap);

    for (int i = 1; i < MAX_INODES; i++) {  /* 从 1 开始，0 为根目录 */
        int byte = i / 8;
        int bit = i % 8;
        if (!(bitmap[byte] & (1 << bit))) {
            bitmap[byte] |= (1 << bit);
            disk_write(fs->disk, 1, bitmap);
            return i;
        }
    }
    return -1;
}

/**
 * alloc_block - 分配一个空闲数据块
 *
 * 遍历块位图，找到第一个空闲块并标记为已用
 * 返回：块号，失败返回 -1
 */
int alloc_block(FileSystem *fs) {
    char bitmap[BLOCK_SIZE];
    disk_read(fs->disk, 2, bitmap);

    for (int i = DATA_BLOCK_START; i < TOTAL_BLOCKS; i++) {
        int byte = i / 8;
        int bit = i % 8;
        if (!(bitmap[byte] & (1 << bit))) {
            bitmap[byte] |= (1 << bit);
            disk_write(fs->disk, 2, bitmap);
            return i;
        }
    }
    return -1;
}
```

#### 文件创建

```c
/**
 * fs_create - 创建文件
 * @fs: 文件系统指针
 * @filename: 文件名
 * @type: 1=文件, 2=目录
 *
 * 步骤：
 * 1. 分配 inode
 * 2. 初始化 inode 结构
 * 3. 在父目录中添加目录项
 *
 * 返回：inode 编号，失败返回 -1
 */
int fs_create(FileSystem *fs, const char *filename, uint16_t type) {
    /* 分配 inode */
    int inode_num = alloc_inode(fs);
    if (inode_num < 0) return -1;

    /* 初始化 inode */
    Inode inode = {
        .inode_id = inode_num,
        .size = 0,
        .type = type,
        .ref_count = 1
    };
    write_inode(fs->disk, inode_num, &inode);

    /* 在根目录添加目录项 */
    dir_add_entry(fs, 0, filename, inode_num);

    return inode_num;
}
```

#### 文件读写

```c
/**
 * fs_read - 读取文件内容
 * @fs: 文件系统指针
 * @fd: 文件描述符
 * @buffer: 数据缓冲区
 * @size: 读取字节数
 *
 * 步骤：
 * 1. 根据 fd 获取 inode
 * 2. 根据 offset 计算块号和块内偏移
 * 3. 读取数据块并拷贝到 buffer
 * 4. 更新 offset
 *
 * 返回：实际读取字节数
 */
int fs_read(FileSystem *fs, int fd, void *buffer, int size) {
    FileDescriptor *desc = &fs->fd_table[fd];
    Inode *inode = read_inode(fs->disk, desc->inode_num);

    int bytes_read = 0;
    char block[BLOCK_SIZE];

    while (bytes_read < size && desc->offset < inode->size) {
        /* 计算块索引和偏移 */
        int block_idx = desc->offset / BLOCK_SIZE;
        int offset_in_block = desc->offset % BLOCK_SIZE;

        /* 读取数据块 */
        disk_read(fs->disk, inode->blocks[block_idx], block);

        /* 计算本次可读字节数 */
        int can_read = BLOCK_SIZE - offset_in_block;
        if (can_read > size - bytes_read)
            can_read = size - bytes_read;
        if (can_read > inode->size - desc->offset)
            can_read = inode->size - desc->offset;

        /* 拷贝数据 */
        memcpy(buffer + bytes_read, block + offset_in_block, can_read);

        bytes_read += can_read;
        desc->offset += can_read;
    }

    return bytes_read;
}

/**
 * fs_write - 写入文件内容
 *
 * 类似 fs_read，但需要分配新数据块
 */
int fs_write(FileSystem *fs, int fd, const void *buffer, int size) {
    FileDescriptor *desc = &fs->fd_table[fd];
    Inode *inode = read_inode(fs->disk, desc->inode_num);

    int bytes_written = 0;
    char block[BLOCK_SIZE];

    while (bytes_written < size) {
        int block_idx = desc->offset / BLOCK_SIZE;
        int offset_in_block = desc->offset % BLOCK_SIZE;

        /* 如果需要新块，则分配 */
        if (inode->blocks[block_idx] == 0) {
            int new_block = alloc_block(fs);
            if (new_block < 0) break;
            inode->blocks[block_idx] = new_block;
        }

        /* 读取现有块（部分写入） */
        if (offset_in_block != 0) {
            disk_read(fs->disk, inode->blocks[block_idx], block);
        }

        /* 计算本次可写字节数 */
        int can_write = BLOCK_SIZE - offset_in_block;
        if (can_write > size - bytes_written)
            can_write = size - bytes_written;

        /* 拷贝数据 */
        memcpy(block + offset_in_block, buffer + bytes_written, can_write);
        disk_write(fs->disk, inode->blocks[block_idx], block);

        bytes_written += can_write;
        desc->offset += can_write;
    }

    /* 更新文件大小 */
    inode->size = desc->offset;
    write_inode(fs->disk, desc->inode_num, inode);

    return bytes_written;
}
```

### 3.3 目录管理模块 (dir.c)

```c
/**
 * dir_add_entry - 在目录中添加目录项
 * @fs: 文件系统指针
 * @dir_inode_num: 目录的 inode 编号
 * @filename: 文件名
 * @inode_num: 文件的 inode 编号
 */
int dir_add_entry(FileSystem *fs, int dir_inode_num,
                  const char *filename, int inode_num) {
    Inode *dir_inode = read_inode(fs->disk, dir_inode_num);

    /* 在目录的数据块中添加目录项 */
    DirEntry entry;
    strncpy(entry.filename, filename, 27);
    entry.filename[27] = '\0';
    entry.inode_num = inode_num;

    /* 查找空闲位置或追加 */
    int block_idx = dir_inode->size / BLOCK_SIZE;
    int offset = dir_inode->size % BLOCK_SIZE;

    if (offset == 0) {
        /* 需要新块 */
        int new_block = alloc_block(fs);
        dir_inode->blocks[block_idx] = new_block;
    }

    /* 写入目录项 */
    char block[BLOCK_SIZE];
    disk_read(fs->disk, dir_inode->blocks[block_idx], block);
    memcpy(block + offset, &entry, sizeof(DirEntry));
    disk_write(fs->disk, dir_inode->blocks[block_idx], block);

    dir_inode->size += sizeof(DirEntry);
    write_inode(fs->disk, dir_inode_num, dir_inode);

    return 0;
}
```

## 四、开发过程中遇到的问题与解决方法

### 问题 1：磁盘文件权限问题

**问题描述**：
```bash
./fs_test disk.img format
Failed to open disk: disk.img
```

**原因分析**：
- 磁盘文件不存在或无写权限

**解决方案**：
```bash
# 创建磁盘文件
touch disk.img

# 检查权限
ls -l disk.img

# 修改权限
chmod 666 disk.img
```

---

### 问题 2：文件名长度超限

**问题描述**：
- 创建文件时文件名超过 27 字符被截断

**原因分析**：
- DirEntry 结构体限制 `filename[28]`

**解决方案**：
```c
/* 在 dir_add_entry 中增加长度检查 */
if (strlen(filename) > 27) {
    printf("Error: filename too long (max 27 chars)\n");
    return -1;
}
```

---

### 问题 3：打开文件数超过限制

**问题描述**：
```bash
fs> open file64
Failed to open file
```

**原因分析**：
- 最多支持 64 个同时打开的文件
- 文件描述符表已满

**解决方案**：
```c
/* 在 fs_open 中增加检查 */
int fs_open(FileSystem *fs, const char *filename, int flags) {
    /* 检查是否有空闲文件描述符 */
    int fd = -1;
    for (int i = 0; i < MAX_OPEN_FILES; i++) {
        if (!fs->fd_table[i].used) {
            fd = i;
            break;
        }
    }
    if (fd < 0) {
        printf("Error: too many open files\n");
        return -1;
    }
    /* ... */
}
```

---

### 问题 4：删除文件后空间未释放

**问题描述**：
- 删除文件后，磁盘空闲空间未增加

**原因分析**：
- `fs_delete()` 未正确释放 inode 和数据块

**解决方案**：
```c
int fs_delete(FileSystem *fs, const char *filename) {
    /* 查找文件 inode */
    int inode_num = find_inode(fs, filename);
    Inode *inode = read_inode(fs->disk, inode_num);

    /* 释放数据块 */
    for (int i = 0; i < 16 && inode->blocks[i] != 0; i++) {
        free_block(fs, inode->blocks[i]);
    }

    /* 释放 inode */
    free_inode(fs, inode_num);

    /* 从目录中删除 */
    dir_remove_entry(fs, 0, filename);

    return 0;
}
```

## 五、创新点与技术优势

### 5.1 与真实文件系统对比

| 对比项 | 本项目 (用户态模拟) | Ext4 (真实文件系统) |
|--------|-------------------|---------------------|
| **inode 数量** | 512 个（固定） | 动态分配 |
| **最大文件大小** | 8KB（直接块） | 16TB（间接块+Extent） |
| **目录结构** | 单层（仅根目录） | 多层目录树 |
| **日志功能** | 无 | 有（防止数据损坏） |
| **权限控制** | 无 | 完整 POSIX 权限 |
| **实现位置** | 用户态 | 内核态 |

### 5.2 设计亮点

1. **简洁的磁盘布局**：
   - 固定位置：超级块（块0）、位图（块1-2）、inode表（块3-34）
   - 便于理解文件系统的核心概念

2. **位图高效管理**：
   - 1 bit 表示 1 块，空间效率高
   - 线性扫描算法，实现简单

3. **用户态实现**：
   - 避免 kernel panic
   - 支持 gdb 调试
   - 跨平台（Linux/Windows）

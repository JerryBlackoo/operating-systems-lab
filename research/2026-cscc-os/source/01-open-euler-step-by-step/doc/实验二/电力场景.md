# 电力场景深度解读

## 实验背景

本实验模拟了智能变电站中嵌入式 Linux 设备驱动的典型工作模式。通过编写一个模拟电力设备的内核模块，学生可以将操作系统课程中的抽象概念（模块、设备文件、并发控制）直接映射到真实的电力行业嵌入式开发场景中。

---

## 模块组件与电力对应物

| 模块组件 | 电力对应物 | 教学意义 |
|----------|------------|----------|
| 加载/卸载日志 | 设备上电/断电状态记录 | 理解驱动生命周期 |
| 模块参数 (`dev_name`, `default_voltage`) | 设备配置（传感器 ID、额定电压） | 动态配置驱动行为 |
| `/dev/power_device` 字符设备 | 电力数据采集接口 | 用户态与内核态交互标准方法 |
| `read` 操作 | 读取实时电压、电流、功率 | 驱动数据上报 |
| `write` 操作 | 下发遥控指令（如调整电压设定值） | 控制类命令下发 |
| 互斥锁 (`mutex`) | 防止并发读取导致数据不一致 | 多线程/多进程安全 |

## 实际应用场景

### 1. 智能变电站监控系统

在智能变电站中，嵌入式 Linux 设备通常负责：

- **电压监测**：实时采集母线电压（110kV、35kV、10kV 等）
- **电流监测**：监测变压器、断路器的负载电流
- **功率计算**：根据电压和电流计算功率，用于负荷预测
- **状态上报**：通过设备文件向监控系统上报数据

### 2. 配电自动化终端（DTU/FTU）

配电自动化终端设备通常运行嵌入式 Linux 系统，内核模块负责：

- **数据采集**：从传感器读取电压、电流、功率等数据
- **远程控制**：接收调度中心的遥控指令（如开关分合闸）
- **本地存储**：将数据存储到本地文件系统或数据库
- **通信接口**：通过 IEC 104、Modbus 等协议与主站通信

### 3. 电力物联网边缘设备

在电力物联网场景中，边缘设备需要：

- **多传感器接入**：同时管理多个传感器（温度、湿度、振动等）
- **数据处理**：在内核态进行数据预处理（滤波、异常检测）
- **低延迟响应**：快速响应电网故障（如过载、短路）

## 实验与实际开发的差异

| 实验模拟 | 实际开发 | 差异说明 |
|----------|----------|----------|
| 模拟数据（固定电压/电流） | 真实传感器数据 | 实际需要 ADC/DAC 接口 |
| 简单字符串格式 | IEC 104/Modbus 协议 | 实际需要协议栈实现 |
| 单设备文件 | 多设备文件（多线路） | 实际需要设备号管理 |
| 内核态互斥锁 | 内核态 + 用户态同步 | 实际需要更复杂的同步机制 |

## 扩展思考与挑战

### 1. 增加温度监测

在 `struct power_data` 中添加 `temperature` 字段：

```c
struct power_data {
    int voltage;
    int current;
    int power;
    int temperature;  /* 新增：温度 (℃) */
};
```

扩展 `read` 输出格式，并实现通过 `write` 写入温度值。

### 2. 过载保护模拟

当功率超过阈值（例如 5000W）时，通过 `printk` 发出内核告警：

```c
if (dev_data.power > 5000) {
    printk(KERN_WARNING "Overload detected! Power: %d W\n", dev_data.power);
}
```

### 3. 使用 procfs 替代 devfs

尝试在 `/proc/power_device` 下创建只读文件输出电力数据：

```c
#include <linux/proc_fs.h>

static int power_proc_show(struct seq_file *m, void *v)
{
    seq_printf(m, "Voltage: %d V\n", dev_data.voltage);
    seq_printf(m, "Current: %d A\n", dev_data.current);
    seq_printf(m, "Power: %d W\n", dev_data.power);
    return 0;
}
```

### 4. 支持多个设备

使用 `miscdevice` 的 `.minor` 自动分配，创建两个设备文件分别代表不同线路：

```c
static struct miscdevice power_misc_line1 = {
    .name = "power_line1",
    ...
};

static struct miscdevice power_misc_line2 = {
    .name = "power_line2",
    ...
};
```

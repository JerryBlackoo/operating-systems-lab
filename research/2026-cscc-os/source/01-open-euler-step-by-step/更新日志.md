## 三、阶段性 Git 提交建议

为方便其他学校"一步一步"学习本实验体系，推荐按以下节点组织 Git 提交：

### 整体提交节点

| 阶段 | 推荐 commit 内容 | 对应里程碑 |
|------|-----------------|-----------|
| commit 1 | 项目初始化、目录结构、README | 项目启动 |
| commit 2 | 实验一：环境搭建脚本 | 环境就绪 |
| commit 3 | 实验二 CP1：模块加载卸载 | 入门层完成 |
| commit 4 | 实验二 CP2：参数传递 | 进阶 |
| commit 5 | 实验二 CP3：字符设备驱动 | 难点突破 |
| commit 6 | 实验三：进程通信三种机制 | 核心层 |
| commit 7 | 实验四：四种调度算法 | 核心层 |
| commit 8 | 实验五：内存管理 | 扩展层 |
| commit 9 | 实验六：字符设备驱动 | 扩展层 |
| commit 10 | 实验七：用户态文件系统 | 扩展层 |
| commit 11 | 实验八 Phase1：UDP Socket | 提升层 |
| commit 12 | 实验八 Phase2：Netfilter | 提升层 |
| commit 13 | 实验八 Phase3：XDP/eBPF | 难点突破 |
| commit 14 | 实验九：iSulad + A-Tune | 综合应用 |
| commit 15 | 文档体系完善、测试脚本、答辩材料 | 最终交付 |

### 单实验内部建议

每个实验内部也建议保留"小步提交"痕迹，例如实验二：

```
commit: 实验2-CP1-基础模块加载
commit: 实验2-CP1-修复dmesg权限问题
commit: 实验2-CP2-添加module_param
commit: 实验2-CP3-实现字符设备
commit: 实验2-CP3-添加电力场景功率计算
commit: 实验2-补充测试脚本test_module.sh
```
